# 🎮 PS4 Games Sales Analysis

This project analyzes PS4 video game sales data using **Python** to understand global sales performance, popular genres, regional sales, release periods, and game performance.

## 🔍 What I Worked On

- Data exploration and understanding
- Data cleaning and handling missing values
- Handling missing publisher values
- Feature engineering
- Sales categorization
- Game performance categorization
- Release period categorization
- Genre-wise sales analysis
- Regional sales analysis
- Top 10 games by global sales
- Global sales distribution
- Performance-wise analysis
- Release period analysis
- Data visualization using **Matplotlib** and **Seaborn**
- Exploratory Data Analysis (EDA)

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

##  Key Analysis

The project explores:

- Global sales by genre
- Average global sales by genre
- Top 10 games by global sales
- Sales distribution across different regions
- Number of games by sales category
- Number of games by release period
- Number of games by performance category
- Average global sales by performance
- Global sales by release period
- Global sales trends over the years
- Genre performance across different performance categories

##  Objective

The main objective of this project is to practice **real-world data cleaning, feature engineering, exploratory data analysis and visualization** using Python and extract meaningful insights from PS4 video game sales data.
